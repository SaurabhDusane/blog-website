# Essay uploads

Upload a Word `.docx` or a text-based `.pdf` directly in this folder. To customize a PDF’s title or summary, add a `.yml` or `.yaml` file with the same base name beside it. The [publishing guide](../../PUBLISHING.md) covers previews, scheduling, and updates.

Existing uploads directly under `posts/` still publish. Put unfinished pieces under `posts/drafts/` and short notes for Loose Threads under `posts/threads/`.

Leave tags and mood blank to let Second Ink sort the essay based on its text. Add entries on `main` to send them through the production publishing workflow.
